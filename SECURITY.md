# Security

Please don't open a public issue for a security problem. Report it privately with **Report a
vulnerability** on this repository's
[Security tab](https://github.com/CatDogBark/bitComposer/security/advisories/new), or email
catdogbark@pm.me.

Say what you found, how to make it happen, and the version (`bitcomposer --version`). Only the
latest release gets fixes.
